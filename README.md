# FAQ-бот на 5 вопросов (HackAlem AI - Репетиция)

Консольный бот, отвечающий на вопросы о репетиции хакатона по ключевым словам.

## Структура
- `faq.txt` — база из 5 пар вопрос-ответ.
- `main.py` — скрипт поиска совпадений по ключевым словам.
